# Karim Baidar — Personal Website

My personal portfolio website, hosted on **GitHub Pages** at [karimbaidar.github.io](https://karimbaidar.github.io/).

## Tech stack

This is a lightweight, responsive static website built with **HTML and CSS**. No JavaScript framework, server, build step, or paid hosting is required.

- `index.html` — portfolio content, accessibility and SEO metadata
- `assets/css/styles.css` — responsive design
- `kb.png` — existing portrait
- `favicon.svg` — site icon

## Local preview

From the repository root:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Deployment

Push changes to the repository's published `main` branch. GitHub Pages serves the files from the repository root at https://karimbaidar.github.io/. No external domain or Cloudflare is needed.

The existing professional introduction and social profile links are preserved.
